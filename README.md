# Marmot Homebrew Tap 🐿️

Install [Marmot](https://github.com/EPeiffer94/Marmot) on **macOS 26 (Tahoe) or later**:

```sh
brew install --cask EPeiffer94/marmot/marmot
```

**On macOS 13–15?** This Homebrew cask is not supported. Download `Marmot-3.2.0.zip` from the [Marmot 3.2.0 release](https://github.com/EPeiffer94/Marmot/releases/tag/v3.2.0), unzip it, and drag **Marmot.app** into **Applications**.
